# Flyguide Travel & Tours site

Static showcase site (HTML/CSS/JS, no build step). Open `index.html` or run `python3 -m http.server` here.

Placeholders to replace in `index.html`: phone `+91 00000 00000`, WhatsApp link, and email `hello@example.com` (also the form `action`). Brand colour: `--accent` in `styles.css`.
